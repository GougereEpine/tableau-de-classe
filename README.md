# Tableau de classe

Tableau interactif pour la classe, dans l'esprit de classroomscreen : équipes et points, chronomètre, minuteur à cadran, heure et date en anglais, consignes de travail, roue des prénoms, phonèmes anglais (UK), zones de texte.

**Ouvrir l'app : https://gougereepine.github.io/tableau-de-classe/**

## Sauvegarde
Rien n'est envoyé en ligne. Les données restent :
- dans le navigateur de l'ordinateur utilisé ;
- dans un fichier `.json` choisi par l'utilisatrice (par exemple sur une clé USB), mis à jour automatiquement avec Chrome ou Edge.

Sur un nouvel ordinateur : Réglages > « Ouvrir une sauvegarde… » puis choisir le fichier `.json`.

## Hors ligne
`index.html` fonctionne aussi seul, ouvert depuis une clé USB, sans internet (polices et sons inclus).
